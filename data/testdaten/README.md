# Testdaten

**Alles hier ist frei erfunden.** Keine echten Kunden, Personen, Tickets oder Zugangsdaten (DSGVO, Datenminimierung).

Geplanter Inhalt:
- Fiktive Tickets inklusive Lösungsweg beim Abschluss
- Spam-Testtickets mit erwarteter Einstufung
- Kundendoku je Testkunde als Markdown. Zugangsdaten nur als Verweis, z. B. „siehe Passwortmanager, Eintrag XY“

Zeitstempel möglichst relativ zu „jetzt“ erzeugen, damit die SLA-Ampel bei der Präsentation noch sinnvoll aussieht.
